Видимая лента X

Радар передаёт текст постов из открытой вкладки «Для вас» вашему локальному OSVED. Он не листает ленту и не выполняет действий в аккаунте.

Укажите этот ID при запуске локального browser-bridge.

Код хранится только до перезапуска браузера. Cookie и пароль X вводить не нужно.

Радар выключен.

  1. Запустите локальный OSVED и подключите расширение.
  2. Войдите в X вручную и откройте вкладку «Для вас».
  3. Оставьте эту вкладку активной. Снимок выполняется только при наличии задачи.

Адрес сервиса: http://127.0.0.1:8769 · Эксперимент, только Chromium.
