# ОСВЕД

Персональный Telegram-бот для новостей и осведомлённости: свои Telegram-каналы,
YouTube-каналы, публичные авторы X/Twitter, RSS и GitHub. Один экземпляр — один
владелец со своей базой, источниками и API-ключами.

## Что умеет

- Находить события, объединять дубли, исследовать источники и готовить новости.
- Принимать публичные Telegram-каналы по ссылке или пересланному посту, с подтверждением.
- Отслеживать новые выпуски своих YouTube-каналов; делать краткую сводку или PDF по запросу.
- Читать публичные посты выбранных X/Twitter-авторов и выполнять тематический X-поиск через Monid.
- Показывать краткую новость, раскрывать контекст и собирать отдельный подробный разбор.
- Сохранять реакции, комментарии, очереди, кеш и учёт расходов в SQLite.
- Показывать недельную карту и людей по уже сохранённым проверенным событиям.

Подписки при первом запуске пустые. Интересы и поиск настраиваются в `config/`.
Примеры для RSS/GitHub и X лежат в `examples/`; они подключаются только после копирования.

## Быстрый старт

Подготовь Docker с Compose, новый Telegram-бот от [BotFather](https://t.me/BotFather),
свой Telegram user ID, ключ [OpenRouter](https://openrouter.ai/settings/keys) и ключ
[Monid](https://app.monid.ai/access/api-keys). У обоих API нужен доступный баланс.

```sh
git clone https://github.com/SlavaXAi/osved.git
cd osved
cp .env.example .env
```

В `.env` заполни `TELEGRAM_BOT_TOKEN`, `ALLOWED_USER_ID`, `OPENROUTER_API_KEY`
и `MONID_API_KEY`. В `config/interests.yaml` укажи свои темы и цели.

```sh
docker compose build
docker compose run --rm newsfeed osved doctor
docker compose up -d
```

Напиши своему боту `/start`, добавь Telegram- и YouTube-каналы. Для X укажи своих
авторов в `config/x-authors.yaml` и/или запросы в `config/sensory-sources.yaml`.
Затем включи расписание:

```sh
docker compose exec newsfeed osved schedule-enable --live
```

Эта последняя команда разрешает фоновый сбор, поиск и LLM-запросы. До неё расписание
выключено; явные запросы YouTube-сводки и подробного разбора могут быть платными.
Изменения `.env` применяются через `docker compose up -d --force-recreate`.
Изменения YAML читаются из подключённого каталога `config/`.

**[Полный короткий гид: Telegram, YouTube, X и диагностика](docs/QUICKSTART.md).**

## Основные команды бота

| Команда | Назначение |
|---|---|
| `/start` | Начать работу |
| `/tgchannels` | Telegram-каналы: список, пауза, удаление |
| `/tg ссылка` | Добавить Telegram-канал через подтверждение |
| `/channels` | YouTube-каналы |
| `/channel ссылка` | Добавить YouTube-канал |
| `/videos` | Найденные выпуски |
| `/report ссылка` | Полный PDF по YouTube-видео |
| `/sources`, `/radar` | Источники и состояние сбора |
| `/news`, `/status` | Очередь новостей и состояние ленты |
| `/week`, `/people` | Локальные обзоры сохранённых событий |
| `/preferences` | Предложения по реакциям без скрытого изменения интересов |

Обычная ссылка на YouTube-видео запускает короткую сводку. Полный PDF запрашивается
отдельной кнопкой или `/report`. Исходный транскрипт и результаты кешируются.

## Границы текущей версии

Telegram-радар даёт события для исследования, а не копию всех постов каждого канала.
Новость требует прочитанного первоисточника; мнения и аналитика без него могут
остаться без карточки. Сбор выполняется по настроенному расписанию и получает
ограниченное окно последних постов; полнота архива и отсутствие пропусков не гарантируются.
Стартовый `RADAR_COLLECT_LIMIT=100` расширяет окно по сравнению с коротким образцом.

X/Twitter читает публичных авторов и поисковые результаты. Личная лента «Для вас»,
закрытые аккаунты и история просмотра не входят в обычное подключение. Для этого
режима не нужен Twitter API token, пароль или cookies; нужен Monid.

В `.env.example` включены учётные лимиты, в том числе для видео. Они не заменяют
лимиты на стороне провайдера и не являются банковской выпиской. VPS оплачивается отдельно.
Тексты источников, профиль интересов и ограниченные примеры реакций могут передаваться
используемым API. Круглосуточная работа требует постоянно включённого хоста.

## Разработка

Нужны Python 3.12+ и [uv](https://docs.astral.sh/uv/). Для локальных запросов источников
также нужен Node 20+ и `npm install -g @monid-ai/cli@0.1.7`;
`monid keys add --key ... --label local` выполняется у себя, с собственным ключом.
Docker устанавливает Monid сам и использует `MONID_API_KEY` из окружения.

```sh
uv sync --frozen --extra dev
uv run osved --help
uv run ruff check app tests
uv run pytest
```

Тестовые профили в `tests/fixtures/config/` используются только в регрессионных тестах.
Биографическая рубрика с каталогом первоначального владельца и его серверные
скрипты в этот пакет не включены. Личные базы и настройки в репозитории отсутствуют.

Лицензия проекта — MIT. Сторонние ресурсы в `app/web/static/vendor/` сохраняют свои лицензии.
